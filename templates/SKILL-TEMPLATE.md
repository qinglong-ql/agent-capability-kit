# DSH 技能说明书模板（复制这个去写新技能）

> **放哪**：`~/.dsh/skills/<英文小写名>/SKILL.md`
> **怎么生效**：放进去后重载会话（`<available_skills>` 是启动时扫描的）
> **关键**：`description` 里必须写**用户可能说的原话关键词** —— DSH 靠它做匹配，写模糊就永远不会被选中。

---

## 模板（直接复制，替换方括号内容）

```markdown
---
name: [英文小写短名，与文件夹同名]
description: [一句话说清「做什么 + 什么时候用」。必须包含用户可能说的原话关键词，例如：用于处理 PDF 相关任务（读取/创建/转换/填表）。当用户提到「PDF、转成PDF、读PDF、PDF填表」时使用。]
---

# [技能中文名]

## 适用场景

- **触发词**：[PDF、转成PDF、读PDF、PDF表单]（写用户真会说的话，不是功能名）
- **典型需求**：
  - 「[把这份文档做成 PDF 存档]」
  - 「[读取这个 PDF 的内容帮我总结]」
- **不适用场景**：[用户只是问「PDF 是什么」→ 直接回答，不调用本技能]（防止误用）

## 前置条件

- **依赖**：[Python 3.x + PyMuPDF + reportlab]
- **环境检查**：[执行前跑 `python -c "import pymupdf"`，报错先装依赖]

## 使用步骤

1. [确认需求：要读取还是创建？目标路径在哪？]
2. [执行第 2 步……]
3. [执行第 3 步……]
4. **验证**：[把结果渲染出来肉眼检查，别只看命令返回码]
5. **交付**：[给出完整路径、关键信息、打开方式]

## 输出规范

- **交付物格式**：[.pdf]
- **保存路径**：[用户指定目录；未指定则放当前工作目录]
- **命名规则**：[中文名、按内容命名（如「税务申报教程.pdf」），禁止乱码编号]

## 注意事项（坑）

- **坑 1**：[reportlab 默认字体不支持中文，必须注册 `C:\Windows\Fonts\msyh.ttc`，否则整页方块]
- **坑 2**：[TTC 字体要用 `subfontIndex=0` 指定索引]
- **坑 3**：[文件「生成了」不等于「排版正确」，必须渲染检查]
- **安全边界**：[不覆盖已有文件、不删除用户原文件]
```

## DSH 特有的注意事项

| 项 | 说明 |
|---|---|
| **技能不冲突** | 同名技能会被去重，只保留先找到的那个 —— 别装两个功能一样的 |
| **两个技能目录** | `~/.dsh/skills/`（用户级，231 个）和 `~/.agents/skills/`（173 个）都会被扫描 |
| **不要在 description 里堆砌关键词** | 会变成「什么都能匹配」= 什么都不准 |
| **中文技能名可以** | 但 `name` 字段用英文更稳（路径和引用不会有编码问题） |
